## shirianki
This is a simple plugin for Japanese language learners to utilize the vocabulary
they've already learned to play Shiritori with them.

## Setup
Under tools, select the note type fields you want to utilize:
- Kanji
- Furigana
- Definition
- Example sentence
- Word type

## Game Modes
You can then play one of two game modes with a timer on/off:
- **Normal Shiritori**: Chain words by matching starting kana
- **ワードバスケット mode**: Similar to the card game where you must match the
  first kana and a randomly selected final kana

## Additional Features
- Option to enable unseen cards in the deck
- Ability to enable non-noun words to be used
- Hint mode that either shows a hint at <25% time left or enables a button to
  show the kanji for a word you could input
- High score logging when hint mode is disabled, saves the last 10 high scores

## Notes

This currently only works for Japanese and only references words within the deck,
so I recommend using a large deck like the Core2k/6k deck for a variety of
possible word options.
